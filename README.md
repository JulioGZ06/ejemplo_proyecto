# Organizador Personal

## Objetivo
El **Organizador Personal** es una aplicación desarrollada en Python diseñada para facilitar la gestión diaria de tareas, notas y actividades personales mediante una interfaz intuitiva y eficiente, ayudando a optimizar la productividad del usuario.

## Tecnologías Utilizadas
- **Lenguaje de programación:** Python 3.x
- **Interfaz Gráfica (GUI):** PyQt5 / PySide6 *(ajusta según la librería gráfica que uses)*
- **Control de versiones:** Git y GitHub
